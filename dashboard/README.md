# Dashboard (Role C shell, Role B charts)

Web UI for paper trading and historical strategy analysis.

## Features
- **Paper Trading:** simulated orders use the live BTC candle feed and never submit exchange orders.
- **Live Price & Position Display:** current price, open position, unrealized PnL, leverage.
- **Backtest Analysis:** full-year trade markers, performance metrics, and a chronological 70/30 held-out split.
- **Equity Curve & Drawdown:** interactive chart plotting historical equity and max drawdown.
- **Trade Log & Signals:** table showing recent signals, risk evaluations, and order execution status.
- **Manual Kill Switch:** one-click button to flatten all positions and halt trading.

## Planned Tech Stack
- React / Next.js / Tailwind CSS / Recharts or Lightweight Charts.
